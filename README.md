# Мои оценки — версия для себя

Один файл `index.html`, который открывается прямо с компьютера: без
установки, без регистрации и без сервера. В нём можно выгрузить свои игры из
Steam (с часами, обложками, скриншотами и описаниями), ставить оценки, писать
впечатления, добавлять фильмы, сериалы и аниме и собирать тирлисты.

Всё, что вы добавите, хранится в вашем браузере на этом компьютере.

## Как скачать и открыть

1. Скачайте архив: [https://github.com/Qaleka/ratings/archive/refs/heads/standalone.zip](https://github.com/Qaleka/ratings/archive/refs/heads/standalone.zip)
2. Распакуйте его в любую папку, например в «Документы».
3. Откройте `index.html` двойным щелчком. Лучше всего — в Chrome, Edge или
   Яндекс Браузере.

Открывайте файл всегда в одном и том же браузере: данные лежат в нём. Ярлык
на рабочий стол можно сделать как к любому файлу.

## Импорт игр из Steam

Нажмите **«Импорт из Steam»** на главной. Понадобятся две вещи.

### 1. Ключ Steam Web API

1. Откройте https://steamcommunity.com/dev/apikey и войдите в Steam.
2. В поле «Доменное имя» напишите `localhost`, согласитесь с условиями и
   нажмите «Зарегистрировать».
3. Скопируйте ключ (32 символа) в поле «Ключ Steam Web API».

Steam выдаёт ключ только аккаунтам, на которых потрачено хотя бы 5 $. Ключ
никуда не отправляется, кроме самого Steam, а галочка «Запомнить» хранит его
только в вашем браузере.

### 2. SteamID64

Откройте https://store.steampowered.com/account/ — под названием аккаунта
есть строка «Steam ID: 7656119…». Эти 17 цифр и есть SteamID64. Подойдёт и
ссылка на профиль вида `https://steamcommunity.com/profiles/7656119…`.

Ещё в Steam должны быть открыты игры: **Профиль → Редактировать профиль →
Приватность → «Сведения об играх: Открытые»**.

### Дальше — две копипасты

Страница открыта с диска и сама спросить Steam не может, поэтому ответы Steam
переносятся вручную:

1. **«Открыть мою библиотеку»** — откроется вкладка с текстом. Нажмите
   `Ctrl+A`, `Ctrl+C`, вернитесь, вставьте текст в поле (`Ctrl+V`) и нажмите
   **«Добавить игры»**. Все игры, в которые вы играли больше часа, появятся с
   часами.
2. **«Обложки, скриншоты и описания»** (по желанию, но так красивее) — то же
   самое для каждой ссылки «Часть 1», «Часть 2»…: открыть, скопировать всё,
   вставить, **«Применить»**.

Импорт можно повторять: новые игры добавятся, у старых обновятся часы, а
оценки и ваши тексты останутся.

## Сохраните копию

Данные живут только в этом браузере: если очистить его данные, они пропадут.
Внизу страницы есть **«Сохранить копию»** — она скачает файл со всеми
отзывами, тирлистами и картинками. **«Восстановить из копии»** вернёт всё из
такого файла — хоть на другом компьютере.

## Новая версия

Скачайте архив по той же ссылке и откройте новый `index.html` в том же
браузере — отзывы останутся на месте. На всякий случай перед этим сохраните
копию.

## Если что-то не так

- **«Steam не принял ключ»** — ключ скопирован не целиком или с пробелом.
- **«Профиль скрывает игры»** — откройте «Сведения об играх» (см. выше),
  подождите минуту и откройте ссылку на библиотеку заново.
- **У игры нет обложки** — пройдите шаг «Обложки, скриншоты и описания».
- **Пусто после повторного открытия** — файл открыт в другом браузере.
  Откройте в прежнем или восстановите из копии.
